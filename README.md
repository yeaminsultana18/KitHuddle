KitHuddle

KitHuddle is a sports kit shop for teams and players in Bangladesh. Customers can buy jerseys, boots, bats, balls and more, and a whole team can order matching kits together with a squad discount.

Features
Shop: categories (Football, Cricket, Basketball), search, price filter, product pages with size-wise stock
Accounts: register, log in, guest browsing, profile with delivery address
Cart and checkout: cash on delivery, order history, order status updates
Squad orders: a captain creates a squad with a join code; members add their name, size, jersey name and number; the discount grows with team size
Size advisor: recommends a size from height and weight
Wishlist, notifications and help chat
Offers: admins create offers with a banner and choose which products get the discount
Admin portal: a separate login for staff; manage products, categories, orders, squads, offers and admins (the owner gives or removes admin roles on the website)
Built with
React + Vite
Tailwind CSS
Firebase Authentication and Cloud Firestore
Run it on your computer
Install Node.js (version 18 or newer).
Clone the project and install the packages:
git clone https://github.com/yeaminsultana18/KitHuddle.git
cd KitHuddle
npm install
Create a file named .env.local in the main folder with the Firebase keys (ask the team for the values; never commit this file):
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_APP_ID=...
Start the website:
npm run dev

Then open the link it shows (usually http://localhost:5173).
